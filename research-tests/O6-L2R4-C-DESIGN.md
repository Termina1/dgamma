# L2R4 Unit C — ratified bundle-release-anchor measure

## Supervisor ruling (verbatim)

> UNIT C DESIGN RULING: use the BUNDLE-RELEASE-ANCHOR measure for the variant normalizer — for each forced root, count the lifecycle steps of OTHER actors strictly between its bundle's release anchor (the LAST release that makes it native-applicable; shared by all roots of the bundle) and the root's actual position; non-forced roots keep the standard root-first count. Rationale: the anchor is fixed by release DATA, not by the positions of other roots, so an admitted adjacent root/lifecycle swap after the anchor changes exactly that root's count by one and no other root's (Begin2 stays between the anchor and S whether or not R has moved) — exact-one decrease holds with arbitrary prefix AND suffix, and zero ⇔ every forced root sits immediately after its anchor bundle position (attached normal form). This matches L2R3's post-release-local 2→1→0. Keep the inherited compatible-cut EarliestAvailableRootBirth as the LEGALITY classification (where a root may sit), NOT as the measure; record the 1,1,0 phenomenon (R's hoist exposes a new S-inversion under compatible-cut counting because of its "no crossed root input" clause) as the audited reason the faithful compatible-cut count is not a stepwise measure. Deliver within Unit C: the anchor measure definition; both moved fixture trails globally 0 under it; exact-one decrease for one admitted swap with arbitrary prefix and suffix; the remaining normalizer obligation = well-founded iteration over the total anchor count (state it; prove on the fixtures if a slot remains). No compatible-cut measure claims.

## Precision / remaining semantic obligations

`EarliestAvailableRootBirth` (CP5AvailabilityAwarePlacement; produced for C12 by L2R2SmallPlacement.smallRootEarliest) classifies compatible placement: all crossed cuts provision-free AND no crossed root input. A faithful per-root compatible-cut lifecycle count has R/S phase values **1,1,0**, not 2,1,0, because moving R exposes S's new eligible inversion. Native-key-only counting would fail global zero for always-free barrier S. Neither is silently used as the variant measure.

The new event algebra uses fixed release-marker identities (actual removal's original ending cut), root-to-marker assignments, and foreign lifecycle events. Roots do not change the counting history. A marker clears only the history count of roots assigned to that marker. Non-forced roots (`Nothing`) retain root-first foreign-lifecycle counts. The actual classifier maps all five lifecycle Action constructors; no lifecycle kind can be silently classified as Other. Native ORemove supplies a marker; OInsert Root supplies an anchored root; other orchestration events count neither as lifecycle nor roots.

Generic algebra operates on fixed authenticated annotations. Transport of root-to-release assignments (especially reborn names/generations), proof that a marker is the LAST native release with barrier closure, and annotation preservation through native arbitrary-prefix/suffix replay remain semantic normalizer obligations. The finite fixture assignment R/S→cut4 is justified by the existing actual Remove1/key release and ordered barrier bundle, not a generic last-release classifier.

A zero count by itself means no counted FOREIGN lifecycle inversion; it does not exclude intervening orchestration steps or same-actor lifecycle edges. Therefore the ruling's full zero⇔AttachedNormalForm/physical-immediacy reading additionally requires the existing grammar, root-before-own-lifecycle, external-order and coverage/decomposition obligations. No bare arithmetic biconditional or global canonical normalizer is claimed.
